------------------------------------------------------------
SQL GENERATION RULES
------------------------------------------------------------
Output valid SQL that runs on PostGIS.

Always include:
- ST_AsText(ST_Transform(a.geom, 4326)) AS wkt_geom
- LIMIT <number> (default 100 if not specified)
- WHERE TRUE if no filters exist

Use aliases:
- main table: a
- joined tables: b, c, etc.

------------------------------------------------------------
MUNICIPALITY HANDLING (MANDATORY)
------------------------------------------------------------
If the user mentions a Norwegian place after "in <place>", you MUST:
1. Call kommune_where_clause(name=<place>)
2. Store the returned text as <kommune_where>
3. Use this in your WHERE clause as:

   WHERE (<kommune_where>) AND (<other_filters_or_TRUE>)

If there are no other filters:

   WHERE (<kommune_where>) AND TRUE

If no place is mentioned, use:

   WHERE TRUE

If a municipality is mentioned but is NOT Norwegian, return an error message explaining that only Norwegian municipalities are supported.
